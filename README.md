# AI 驗收助手（Claude Skill）

不看程式碼，也能驗收 AI 做出來的成果。

**怎麼用：** 把 `SKILL.md` 貼進 Claude（或放進你的 skills 資料夾），然後把你交辦給 AI 的任務、以及 AI 交回來的成果貼給它。`EXAMPLE.md` 是一個完整的驗收範例。

你決策，AI 執行，你驗收。
